# JKSpeak 최종 업데이트 대조표

## 확인 기준

사용자가 다시 첨부한 Bee 설계 문서는 앞서 제공한 문서와 동일하다. GitHub `main`의 `aff25a0`에는 배포 경로 수정만 있었고, 학습 흐름·성장 화면·설정 화면 개편은 아직 없었다. 이번 변경은 그 개편을 통합하고 JKSpeak 브랜드로 정리하는 변경이다.

‘프로토타입에서 작동함’, ‘이번 정적 앱에서 구현함’, ‘외부 서버가 필요한 향후 기능’을 구분한다. 원문 연구 인용·해외 서비스 평가는 독립 재검증하지 않았고, 이를 JKSpeak의 효과나 성적 향상 근거로 표시하지 않는다.

## JKSpeak 브랜드

Bee/벌/꿀 중심 표현을 제품 화면에서 제거한다. 브랜드 마크는 **말풍선 안의 음성 파형**이며, 저장소에 사용자가 추가한 캐릭터 `logo.png.png`는 준비 단계의 보조 학습 파트너로만 사용한다. 시험 중에는 질문과 답변에 집중한다.

| 역할 | Light | Dark | 사용 원칙 |
|---|---|---|---|
| Canvas | `#FAF8F4` | `#14212E` | 차분한 배경 |
| Surface | `#FFFFFF` | `#1C2C3B` | 준비·질문·답변 카드 |
| Academic Ink | `#1C2D3F` | `#EDF2F6` | 본문·브랜드·제목 |
| Calm Teal | `#236B70` | `#9ED5CE` | 학습 상태·현재 탐색·포커스 |
| Terracotta | `#B34425` | `#EFAB8D` | 주요 실행 버튼 |
| Supporting text | `#526272` | `#B6C6D2` | 설명·개인정보·근거의 한계 |

Light CTA에는 흰 글씨, Dark CTA에는 Ink 글씨를 쓴다. 기존 Bee 기반 저장 키 `bee-independent-v1`, 녹음 DB `bee-audio-v1`, 기존 세션 export 형식 식별자는 호환성을 위해 유지한다. 이는 화면의 Bee 브랜드를 유지한다는 의미가 아니다.

## 항목별 반영 결과

| 설계 항목 | 이번 반영 | 구현 범위 / 남은 차이 |
|---|---|---|
| 사용자층과 시험 유형 정교화 | 구현 | University Oral, Viva / Oral Defence, Presentation Q&A. 각 유형의 저작 시작 질문. |
| 시험별 엔진 분리 | 기초 구현 | 유형별 질문·설명 분리. IELTS/TOEFL/PTE의 공식 엔진·채점은 제공하지 않음. |
| 온보딩·목표 설정 | 구현 | 유형, Guided/Mock, 집중 기술 1개, 선택적 자신감, 자료·루브릭·사용자 질문. |
| Guided / Mock | 구현 | Guided는 힌트·자료 접근, Mock는 숨김. 타이머·중단·복구·직접 입력 유지. |
| 후속 질문 | 수동 연습 구현 | 실제 답변 일부를 인용하는 기술별 고정 도전 질문 추가. AI의 의미 분석이나 실시간 시험관으로 표현하지 않음. |
| 자료 기반 Viva | 수동 연습 구현 | PDF/TXT/MD·노트·루브릭과 사용자 문항을 함께 활용. 자료 기반 AI 생성은 미연결. |
| 발화 근거 피드백 | 자기점검 구현 | 인용이 저장 답변에 존재하는지 검증. 강점·연습 필요·근거 부족/전사 불확실 선택. 의미의 정확성 자동 판정은 없음. |
| Examiner 평가 | 구현 | 동일 기기의 사람이 점수·피드백 입력. 자기점검·자신감과 분리. 공식 점수로 주장하지 않음. |
| 재도전·개선 비교 | 구현 | 개별 문항 및 약한 문항 재연습, 원본 인덱스 연결, 이전/현재 답변 비교. 원본 삭제 시 비교 숨김. |
| 다른 질문으로 전이 | 구현 | 같은 기술을 다른 저작 질문에 적용. 자동 향상 판정은 없음. |
| 학습 프로필·반복 약점 | 기초 구현 | 최근 10개 세션의 인용 포함 자기점검 중 연습 필요 표시를 집계. 자동 능력 진단은 없음. |
| 주간 계획·기록 | 구현 | 최근 7일 목표 세션 수, 실제 완료 수, 자기점검→재도전→전이 수행 기록. 활동 수와 능력 점수를 구분. |
| 난이도 자동 적응 | 미연결 | 수동 목표·연습 조건 선택 제공. 자동 난이도 추정이나 승급은 없음. |
| 성장 측정 | 기초 구현 | 실제 답변 비교·자기보고 자신감 전후·시험관 점수 분리. 검증된 능력 향상이나 학습 효과를 계산하지 않음. |
| 음성·오류 복구 | 구현 | 브라우저 받아쓰기, 로컬 녹음, 명시적 동의·활동 상태·거절 시 타이핑 유지·녹음 다운로드/삭제. |
| 저장·백업·전체 삭제 | 구현 | 기존 localStorage/IndexedDB 호환, 진행 중 세션 포함 텍스트 내보내기, 전체 텍스트·녹음 삭제. 계정·클라우드 복원은 없음. |
| 반응형·접근성·다크 모드 | 구현 | 390px, 200% 확대, 키보드 skip link, 44px 조작 영역, live region. 영어 UI 유지. |
| Pages / Netlify 경로 | 구현 | 상대 자산 경로, 실제 루트 PDF 모듈과 worker. `/`와 `/JKSpeak/`에서 회귀 검증. |
| 실시간 AI Examiner·평가자 분리 | 미연결 | 서버·모델·인증·사용 동의·평가 정책이 필요함. GitHub Pages만으로 구현하지 않음. |
| WebRTC·서버 전사·고급 발음 분석 | 미연결 | 별도 음성 서비스·단기 세션 자격증명·정확도 검증 필요. |
| 계정·클라우드 동기화·원격 시험관 | 미연결 | 인증·권한·저장소·개인정보 정책과 서버 구현 필요. |
| 다국어 안내 | 미구현 | 현 저장소의 영어 UI 지침을 유지. 사용자 자료나 답변을 임의 번역하지 않음. |

서버가 필요한 항목은 이번 정적 앱 개편의 완료 항목으로 계산하지 않는다. 이를 활성화하려면 제공자·서버 배포 위치와 보안 설정을 별도로 정하고 실제 연결을 검증해야 한다.

## 검수 방법

- `node --test tests/oral-coach.test.mjs`: 기존 기록, 인용 검증, 약점 집계, 정확한 재도전 원본 연결, 후속 질문, 7일 활동 집계.
- `python3 tests/deployment_smoke.py`: 루트 및 `/JKSpeak/`에서 앱·scope·CSS·이미지·모듈·PDF worker·skip link.
- `JKSPEAK_TEST_URL=http://127.0.0.1:8082 python3 tests/browser_smoke.py`: TXT/PDF, Guided/Mock, 중단 복구, 자기점검, 시험관 채점, 재도전·전이·후속 질문, 자신감/목표 저장, 다크 모드, 내보내기, 마이크 거절, 합성 마이크 녹음/재생/삭제, 모바일, 전체 데이터 삭제.
- 실제 마이크 품질·받아쓰기 정확도·Safari/Firefox·공개 Pages의 최신 배포 응답은 별도 확인 대상이다. 네트워크 정책상 라이브 사이트나 배포 상태를 읽지 못하면 확인했다고 표현하지 않는다.
